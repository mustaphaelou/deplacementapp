# Agent docs

Domain-specific documentation for AI agents working in this repo.

| File | What it is | When to reach it |
| --- | --- | --- |
| `issue-tracker.md` | GitHub issue tracker conventions, CLI patterns, triage labels | Working with issues, PRs, or triage |
| `domain.md` | How to consume domain docs (CONTEXT.md, ADRs, glossary) | Exploring the codebase or naming domain concepts |
| `testing.md` | Testing conventions and suite count baseline | Running or writing tests |
| `release.md` | Release process (release-as-ticket) | Cutting a release |
| `frontend-drift.md` | Frontend drift automation rules and traps | Working on UI or running the drift checker |
| `coding.md` | Implementation-time coding conventions | Writing code |
